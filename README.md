# linux-practice

Практика по администрированию Linux (Ubuntu 24.04, Multipass).

## Что внутри
- `server-info.sh`: скрипт-«паспорт сервера» (система, память, диск, сеть, порты, службы)
- `server-info.txt`: пример вывода

## Чему научился
- Процессы: `ps`, `top`, `kill`, load average
- Службы: `systemctl`, `journalctl`, своя systemd-служба
- Диагностика: `free`, `df`, `uptime`, `ss`
