# Процессы: задания 1–4

## Задание 1. Процессы nginx
Команда:
```bash
ps -ef | grep nginx
```
Результат: 6 процессов, два master (системный nginx (порт 80) и nginx в контейнере Docker(порт 8080)).
Рабочие процессы (worker) идут от пользователей `www-data` (системный) и от пользователя контейнера.
Процесс master есть родитель процессов worker

## Задание 2. Пять процессов с наибольшей памятью
Команда:
```bash
ps -ely --sort=-rss | head -n 6 | awk '{print $3}' вывод PID 976,758, 284,327, 837
ps -eo pid,user,%mem,comm --sort=-%mem | head -6   вывод USER root
ps -eo pid,user,%mem,rss,comm --sort=-%mem | head -n 6 вывод %MEM 3.9 2.4 1.3 1.3 1.1
```

## Задание 3. Остановка процесса
```bash
yes > /dev/null &
kill <PID>
```
Процесс `yes` загружал одно ядро на ~100%. После `kill` (сигнал SIGTERM, 15) процесс завершился.
